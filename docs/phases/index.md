# Design Phase Records

This directory contains the chronological work history for the design lifecycle.

Phase records are evidence of how the design was developed. They are not automatically the current source of truth; durable conclusions belong under [`../canonical/`](../canonical/index.md).

## Lifecycle

Each high-level phase:

1. begins with an `NNN-A` start gate;
2. derives only the dependency-safe subphases required by the project;
3. proceeds through those design subphases;
4. ends with a consolidation, exit review, and handoff;
5. updates canonical knowledge as durable conclusions become established.

## Entry point

Begin with [Phase 000 — Project Intake & Product Definition](000/index.md).

Later high-level phases should be added only after their methodological intention has been established. The template should not pre-populate a false fixed sequence beyond what has been explicitly reviewed and adopted.
